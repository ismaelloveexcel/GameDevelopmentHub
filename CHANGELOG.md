# Changelog

All notable changes to this project will be documented in this file.

This project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## Versioning Rules

- **MAJOR** version: Incompatible API changes
- **MINOR** version: Backwards-compatible new features
- **PATCH** version: Backwards-compatible bug fixes

Pre-1.0.0 releases may include breaking changes in minor versions.

## [0.1.0] - 2026-01-28

### Added
- Initial repository governance structure
- CONTRIBUTING.md with contribution guidelines
- CODE_OF_CONDUCT.md
- Pull request and issue templates
- CHANGELOG.md with versioning documentation
- .editorconfig for consistent formatting
- CI workflow with strict ESLint tracking (existing warnings logged, not blocking)

### Repository State
- React Native 0.72.6 with Expo SDK 49
- TypeScript 5.1+ strict mode
- Pixi.js, Babylon.js, and A-Frame engine wrappers
- 15 game templates across 2D, 3D, and VR/AR categories
- Jest test suite with initial coverage
- GitHub Actions CI/CD pipelines
