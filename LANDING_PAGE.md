# GameForge Mobile - Landing Page

This is the main landing page for the GameForge Mobile repository, designed for non-technical users to easily understand and manage the automated game development system.

## 🌐 Accessing the Landing Page

### Option 1: GitHub Pages (Recommended)
If GitHub Pages is enabled for this repository:
- Visit: `https://ismaelloveexcel.github.io/GameDevelopmentHub/`

To enable GitHub Pages:
1. Go to repository Settings
2. Click "Pages" in the left sidebar
3. Under "Source", select "Deploy from a branch"
4. Select branch: `main` or `copilot/create-folders-and-add-files`
5. Select folder: `/ (root)`
6. Click Save
7. Wait 1-2 minutes for deployment

### Option 2: Local Viewing
1. Clone the repository
2. Open `index.html` in any web browser
3. Navigate through the interface

### Option 3: Raw GitHub File
Open in browser: `https://github.com/ismaelloveexcel/GameDevelopmentHub/blob/main/index.html` and click "View raw"

## 🎨 Customization

The landing page uses CSS variables for easy customization. Edit the `:root` section in `index.html`:

```css
:root {
    --primary: #6366f1;        /* Main color */
    --secondary: #ec4899;       /* Accent color */
    --success: #10b981;         /* Success messages */
    /* ... more colors */
}
```
